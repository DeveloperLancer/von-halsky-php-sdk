# Generated PHP API reference

The hand-written [operation reference](./reference/README.md) is the primary source for using the SDK: it explains scope, request models, response semantics, and operational constraints for every resource method.

For class-level PHPDoc and source links, generate supplementary API output locally:

```bash
composer docs-build
```

The generated site is written to `build/docs/api`. It is a build artifact and is not committed or linked as a public website. Regenerate it from the same revision as the SDK code you are inspecting.
